Phase 1 is closed: the audit and the first game on SDE29 October 2026

The Phase 1 cut went through an audit. Five checks by agents and an independent review found 25 bugs, three of them critical: a script memory leak stopped the world after 15 seconds of heavy fire, headshots did not count on bots spawned from templates, and animation events went silent after a rewind. All are fixed, and the engine is tagged stable.

A long run of 60,000 ticks matches bit for bit between the native build and the browser.

Landslide now runs on SDE. Agents ported it one to one, with tests that check every number against the original. Next the game grows: a collapse into debris, seven biomes, a ghost of your best run. Over the Edge and Sky Lantern move to SDE next.

By the evening much of it is in the game. The collapse breaks the world apart: platforms crumble into tumbling debris, and cracks run ahead of the edge. Seven biomes are in: meadow, hills, canyon, glacier, cave, volcano and valley, each with its own light and backdrop. Surfaces matter now: ice never holds the wedge, wood holds it on any face, crystal bounces it back. Landings shake the camera, a hard hit freezes the action for an instant, and a jump after a fall starts a new run at once.

Day five28 October 2026

The day was about saves: they must not break in any future version of a game. A save is now a plain list of facts: where the hero stands, how much health is left, what has already happened in the story. If a new version drops something, the game loads the rest and shows what went missing. And the file itself survives the computer switching off in the middle of a save.

The engine also got projectiles: a bullet goes through a thin board or ricochets, a rocket chases its target, an explosion throws fragments. Controls can now be remapped, and menus follow the gamepad. By night the agents began putting everything from these days into one test game: once it passes, the engine is due for a big audit.

Day four27 October 2026

The busiest day so far: six agents worked on the engine at once, and every change went into the history only after its test passed. A character you can steer with a gamepad arrived, and so did a running fox. Hits got heavier: the action freezes for a moment and the camera shakes. The picture gained water, grass in the wind and up to 256 lights in a frame, and games got menus and dialogues.

Meanwhile a cloud review went through the new code, and the agents are closing what it found one by one. And the engine got a logo: a gumdrop with eyes, peeking over an edge.

Day three26 October 2026

We got to the looks. Terrain from a height map arrived, along with models from Blender with all their textures, lamps, sparks and a crackling campfire. Game logic is now written in TypeScript, and a script can change while the game runs. When an agent edits the world, the change shows up in the open editor right away, and you can undo it.

Day two25 October 2026

The engine learned to behave the same on a computer and in a browser: the same input gives the same result, and the picture matches. The editor arrived. You can run the game in it, pause and step through it, and the Report button saves the moment where something went wrong. The ball and the slide on the home page were computed by the engine itself.

Day one24 October 2026

We woke up with an idea: a game engine where AI agents do most of the work, while a person sets the direction and decides what is fun. We spent the day working out what it should be and writing the decisions down. The main one: the world is stored as text, so an agent can read and edit it like ordinary code.
